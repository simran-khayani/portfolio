# Portfolio refinement checklist

## Phase A — content and assets

- [x] Read the supplied brief and the files available in `Assets/` and `Logos/`.
- [x] Keep the resume as the source of truth for roles, dates, education, project facts and numbers.
- [x] Keep editable portfolio copy and repeatable content in one clearly labeled object in `content.js`.
- [x] Keep the existing profile image, organization marks, project brief and working resume PDF; document unavailable assets in `MISSING.md`.
- [x] Add the missing-item list, open questions and ready-to-paste follow-up prompts.

## Phase B — editorial layout and responsive styling

- [x] Create a distinctive, restrained blue-and-sand editorial identity with generous type and space.
- [x] Present every requested section in order with original, concise copy.
- [x] Replace the dashboard mockup with an honest project-art placeholder until a real screenshot is available.
- [x] Make navigation, portfolio cards, skills, contact details and social links readable and accessible.
- [x] Adapt the composition to phone, tablet and desktop widths without horizontal overflow.
- [x] Include semantic landmarks, a skip link, visible focus, descriptive image text, metadata and the SK SVG favicon.

## Phase C — interactions and motion

- [x] Add active-section navigation, a progress indicator and an accessible mobile menu that closes on selection and Escape.
- [x] Add restrained hero/reveal motion, hover feedback and reduced-motion behavior.
- [x] Add keyboard- and pointer-draggable editorial stickers, with touch-safe placement.
- [x] Add desktop-only magnetic buttons, copy-email feedback, interactive skill chapters and a non-blocking easter egg.
- [x] Ensure content remains available if JavaScript observers or animations do not run.

## Phase D — quality checks

- [x] Check that all required facts and numbers are present and no phone number is shown.
- [x] Check asset paths, resume download and external project/social destinations.
- [x] Validate rendered content, mobile navigation, skill controls, email copying and responsive overflow in a browser.
- [x] Review the final diff and push the completed changes to the configured remote.

## Definition of done

- [x] Every section has accurate content or a clearly marked asset placeholder.
- [x] Experience, recognition, project, education, skills, life and contact details render from `content.js`.
- [x] No unsupported roles, dates, performance claims, awards or phone number have been introduced.
- [x] The design follows the requested editorial lookbook direction without using third-party brand assets.
- [x] Navigation, motion preferences, keyboard access, copy feedback, resume and project links are in place.
- [x] Missing files and confirmation questions are easy to find in `MISSING.md`.
